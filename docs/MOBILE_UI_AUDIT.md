# Mobile UI Audit & Architecture

## Mobile Layout Standards
- **Viewport**: 100dvh mobile smartphone screen with zero horizontal overflow (`overflow-x-hidden`).
- **Header**: Pinned status bar with clock, 5G, battery, and top navigation header.
- **Bottom Navigation**: 5-tab navigation (`Home`, `Explore`, `Craft AI`, `Orders`, `Portal`) permanently pinned at the bottom of the viewport.
- **Touch Optimization**: Min 44px tap targets, swipeable chip bars, and modal bottom sheets.
